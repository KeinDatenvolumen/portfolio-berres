# WG-Held – Der digitale WG-Planer

Dieses Projekt entsteht im Rahmen der Portfolioprüfung „Einführung Webtechnologien“ im Modul „Fortgeschrittene Systementwicklung“ an der DHBW Mosbach.

## Projektidee

**WG-Held** ist eine interaktive Webanwendung für Wohngemeinschaften, mit der sich gemeinsame Einkäufe, Ausgaben und Putzpläne übersichtlich an einem Ort organisieren lassen. Alle Eingaben werden lokal im Browser (`localStorage`) gespeichert.

## Seitenstruktur

- `index.html` – Dashboard & Gemeinsame Einkaufsliste (Einträge anlegen, filtern, erledigen, löschen)
- `putzplan.html` – Wöchentlicher Putz- & Aufgabenplaner mit Fortschrittsanzeige
- `finanzen.html` – WG-Kassensturz & Ausgaben-Rechner mit Pro-Kopf-Aufteilung

## Startanleitung

1. Repository klonen oder ZIP-Archiv entpacken.
2. Die Datei `index.html` direkt in einem aktuellen Webbrowser (z. B. Google Chrome) öffnen.
3. Es werden keine externen Abhängigkeiten oder Server benötigt.
